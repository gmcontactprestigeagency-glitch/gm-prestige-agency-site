GM PRESTIGE AGENCY — SITE MULTILINGUE
======================================

CONTENU
- index.html : français
- en/index.html : anglais
- es/index.html : espagnol
- pages de mentions légales et confidentialité dans les 3 langues
- assets/style.css : design responsive
- robots.txt et sitemap.xml : aide à l'exploration SEO

AVANT PUBLICATION — IMPORTANT
1. Remplacez partout https://VOTRE-DOMAINE.fr par l'URL publique réelle du site.
   Cela concerne les balises canonical, hreflang, robots.txt et sitemap.xml.
2. Complétez les pages mentions-legales.html avec votre identité juridique réelle,
   statut, adresse requise et hébergeur. Ne publiez pas les champs entre crochets.
3. Adaptez la politique de confidentialité à vos outils et pratiques réels.
4. Vérifiez les obligations applicables à votre activité en France.

PUBLICATION GRATUITE AVEC GITHUB PAGES
1. Connectez-vous à https://github.com/
2. Créez un dépôt public nommé gm-prestige-agency-site.
3. Téléversez tous les fichiers et dossiers de ce ZIP (pas le ZIP lui-même).
4. Ouvrez Settings > Pages.
5. Dans Build and deployment, choisissez Deploy from a branch.
6. Sélectionnez main et /(root), puis Save.
7. GitHub affichera l'adresse publique du site, généralement :
   https://VOTRE-PSEUDO.github.io/gm-prestige-agency-site/
   Dans ce cas, utilisez cette adresse exacte dans les fichiers SEO au lieu
   de https://VOTRE-DOMAINE.fr, en conservant les chemins /en/ et /es/.

RÉFÉRENCEMENT
- Le sitemap et les balises multilingues aident les moteurs à découvrir les pages.
- Après publication, ajoutez le site dans Google Search Console et envoyez sitemap.xml.
- L'indexation et le classement ne sont jamais garantis ni instantanés.
